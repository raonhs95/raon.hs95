# 참가자용 에듀테크 AI 실습 안내

## 실습 시작

1. 진행자가 안내한 [완성작](../showcase/README.md)을 선택합니다.
2. 프로젝트 설명에서 준비 사항과 로그인 필요 여부를 확인합니다.
3. 실행 링크를 열거나 안내에 따라 파일을 다운로드합니다.
4. 제공된 예시로 한 번 실행하고 결과를 확인합니다.

## 내 수업에 적용하기

- 내가 담당하는 학년과 교과:
- 해결하고 싶은 수업의 어려움:
- 학생이 달성할 학습 목표:
- 사용할 기능과 바꿀 내용:
- 교사와 학생의 활동 순서:
- 필요한 시간과 기기:
- 학습 결과를 확인할 방법:

## 결과 확인

- [ ] 주요 기능을 직접 사용했습니다.
- [ ] AI가 만든 내용의 사실 여부와 표현을 확인했습니다.
- [ ] 학생 개인정보 대신 예시 데이터를 사용했습니다.
- [ ] 수정하거나 다시 공유할 때의 이용 조건을 확인했습니다.
- [ ] 다음 수업에서 시도할 활동 한 가지를 정했습니다.

실행 문제가 생기면 프로젝트 이름, 기기·브라우저, 오류가 발생한 단계를 적어 진행자에게 전달합니다. 화면을 공유할 때는 개인정보와 계정 정보를 가립니다.
