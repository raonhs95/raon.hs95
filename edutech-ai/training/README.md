# 에듀테크 연수 자료

완성된 프로젝트를 활용해 교사가 직접 실습하고 수업 적용안을 만드는 자료입니다.

- [진행자용 연수 진행안](facilitator-guide.md): 사용할 프로젝트, 시간 배분, 사전 준비를 기록합니다.
- [참가자용 실습 안내](participant-guide.md): 실행부터 수업 적용까지 따라갑니다.
- [완성작 목록](../showcase/README.md): 실제로 사용할 결과물을 선택합니다.

연수별 자료가 늘어나면 `YYYY-MM-DD-연수주제` 폴더를 만들고 진행안과 참가자 안내를 복사합니다. 각 폴더에는 사용한 프로젝트 버전과 발표 자료, 활동지의 위치를 기록합니다.
