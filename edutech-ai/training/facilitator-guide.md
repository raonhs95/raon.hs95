# 진행자용 에듀테크 AI 연수 진행안

아래는 90분 실습 연수의 기본 양식입니다. 대상과 프로젝트에 맞게 시간을 조정합니다.

- 대상과 인원:
- 사용할 프로젝트와 버전:
- 참가자에게 공유할 링크:
- 준비물과 계정:
- 연수 목표: AI 결과물을 실행하고, 자신의 수업에 맞춘 적용안 한 가지를 작성합니다.

## 진행 순서

| 시간 | 활동 | 확인할 결과 |
| --- | --- | --- |
| 0~10분 | 교육 문제와 완성작 시연 | 활용 목적 이해 |
| 10~25분 | 접속 및 기본 실행 | 참가자별 실행 성공 |
| 25~50분 | 안내에 따른 실습 | 실습 결과 한 가지 |
| 50~70분 | 학년·교과에 맞게 수정 또는 활용안 작성 | 개인별 적용안 |
| 70~85분 | 결과 공유와 동료 피드백 | 개선점 한 가지 |
| 85~90분 | 정리 및 자료 위치 안내 | 후속 활용 방법 확인 |

## 사전 준비

- [ ] 연수 기기와 네트워크에서 직접 실행했습니다.
- [ ] 로그인 필요 여부, 무료·유료 조건을 안내했습니다.
- [ ] 참가자용 자료와 파일 다운로드를 확인했습니다.
- [ ] 인터넷 장애에 대비한 화면 자료와 대체 활동을 준비했습니다.
- [ ] 공개 가능한 가상 데이터로 실습을 구성했습니다.
- [ ] 사용 버전을 고정하고 실행 링크와 자료 링크를 구분했습니다.

## 연수 후 기록

자주 나온 질문, 실행 오류, 개선 요청과 다음 연수에 반영할 점을 기록합니다. 공개 기록에는 참가자의 개인정보를 포함하지 않습니다.
