# 프로젝트 이름

이 파일은 복사하여 사용하는 양식입니다. 안내 문구와 빈칸을 실제 내용으로 바꾼 뒤 공유하세요.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 한 줄 소개 | 어떤 교육 문제를 어떻게 돕는지 작성 |
| 대상 | 학년, 교과, 사용자를 작성 |
| 학습 목표 | 활동 후 학습자가 할 수 있는 행동을 작성 |
| 상태 | 기획 / 제작 중 / 검증 중 / 공유 가능 중 선택 |
| 제작 도구 | AI 도구와 제작 환경, 확인 가능한 모델·버전 |
| 배포 버전 | 예: v1.0.0 |
| 마지막 실행 확인일 | YYYY-MM-DD |
| 이용 조건 | 본인 자료와 외부 자료의 이용 조건을 구분하여 작성 |

## 시작하기

- 실행 화면: 확인한 공개 링크를 작성합니다. 없으면 아래 다운로드 실행 절차를 작성합니다.
- 다운로드: 배포 파일의 링크를 작성합니다.
- 준비 사항: 기기, 브라우저, 인터넷, 로그인, 비용, 카메라·마이크 사용 여부를 작성합니다.

### 실행 순서

1. 파일 또는 링크를 여는 방법을 작성합니다.
2. 첫 화면에서 입력하거나 선택할 것을 작성합니다.
3. 정상 실행 시 나타나는 화면이나 결과를 작성합니다.

### 실행이 어려울 때

증상, 확인 방법, 해결 방법과 인터넷이 안 될 때 사용할 대체 활동을 작성합니다.
