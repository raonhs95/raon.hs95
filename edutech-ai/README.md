# 에듀테크 AI 프로젝트와 연수 자료

AI로 만든 교육용 결과물과 제작 과정을 모으는 공간입니다. 완성된 프로젝트는 실행 방법, 수업 활용 예시, 연수 실습 자료를 함께 제공하여 다른 교사도 직접 사용하고 자신의 수업에 맞게 적용할 수 있도록 합니다.

## 연수 참가자 안내

1. [완성작 목록](showcase/README.md)에서 실습할 자료를 선택합니다.
2. 해당 프로젝트의 준비 사항과 실행 방법을 확인합니다.
3. [참가자 실습 안내](training/participant-guide.md)에 따라 직접 사용하고 수업 적용안을 작성합니다.

현재는 자료를 쌓기 위한 기본 구조이며, 등록된 완성작은 없습니다.

## 제작자 안내

1. [프로젝트 템플릿](templates/project/README.md)을 복사하여 `projects/프로젝트-이름/` 폴더를 만듭니다.
2. 목적, 대상, 제작 과정과 실행 방법을 작성하고 원본 파일을 넣습니다.
3. 다른 사람이 설명만 보고 실행할 수 있는지 확인합니다.
4. [공유 준비 안내](guides/sharing.md)를 확인하고 완성작 목록에 등록합니다.
5. [연수 진행안](training/facilitator-guide.md)에 사용할 프로젝트와 배포 버전을 기록합니다.

## 운영 원칙

프로젝트 상태는 `기획 → 제작 중 → 검증 중 → 공유 가능`으로 기록합니다. 공개 저장소에서는 제작 중인 파일도 누구나 볼 수 있으므로, 비공개 자료는 처음부터 올리지 않습니다. 학생 실명·사진·성적, 계정 비밀번호와 API 키 대신 가상 예시 데이터를 사용합니다.

자료의 수정·재배포 조건은 각 프로젝트에 명시합니다. 외부 이미지·음원·폰트·코드는 출처와 이용 조건을 함께 기록합니다. 상세 기준은 [자료 이용 안내](USAGE.md)를 따릅니다.
