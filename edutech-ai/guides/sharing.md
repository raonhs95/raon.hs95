# 완성작 공유와 배포

완성작은 실행할 수 있는 결과물과 사용 설명, 이용 조건을 함께 제공해야 연수 이후에도 활용할 수 있습니다.

## 공유 전 확인

- [ ] 처음 사용하는 사람이 README만 보고 실행할 수 있습니다.
- [ ] 실행 링크 또는 다운로드 파일이 실제로 열립니다.
- [ ] 로그인, 비용, 인터넷과 기기 조건을 적었습니다.
- [ ] 실제 확인한 기능과 알려진 한계를 적었습니다.
- [ ] 학생 개인정보, 비밀번호, API 키를 포함하지 않았습니다.
- [ ] 이미지·음원·폰트·코드의 출처와 이용 조건을 적었습니다.
- [ ] 연수에 사용할 버전과 마지막 확인일을 적었습니다.
- [ ] 완성작 목록과 연수 자료의 링크를 확인했습니다.

## 결과물 종류별 공유

| 종류 | 공유할 항목 |
| --- | --- |
| HTML 기반 도구와 게임 | 실행 사이트 주소 또는 다운로드 파일, 실행 절차 |
| PDF와 활동지 | 다운로드 파일, 대상 학년, 활용 순서 |
| 프롬프트 모음 | 입력 예시, 도구, 출력 예시, 검토 기준 |
| 외부 AI 서비스 결과물 | 열람 링크, 로그인·비용 조건, 복제 가능 여부 |
| 서버나 API가 필요한 도구 | 설치·실행 절차, 환경 설정 예시, 비밀 키를 넣지 않은 코드 |

GitHub에 코드를 올린 것만으로 실행 사이트가 만들어지지는 않습니다. 웹 실행 화면이 필요하면 별도로 배포하고 실제로 확인한 주소를 기록합니다.

## 연수 버전 관리

연수 직전에는 사용할 버전을 정하고 파일 묶음과 자료 링크를 함께 보관합니다. 예를 들어 `프로젝트이름-v1.0.0.zip`처럼 이름을 붙이고 프로젝트의 CHANGELOG에 변경 내용을 기록합니다. GitHub Release를 사용하는 경우 해당 배포 페이지 링크를 완성작 목록에 넣습니다.

연수 자료는 특정 배포 버전을 가리키게 하고, 최신 개발 파일은 프로젝트 폴더에서 관리합니다. 이후 기능이 바뀌어도 연수 참가자가 같은 자료를 다시 찾을 수 있도록 기존 배포 파일과 안내를 유지합니다.
