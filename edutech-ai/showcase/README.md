# 연수용 완성작 목록

실행 확인과 사용 설명이 준비된 결과물을 모읍니다. 연수 참가자는 프로젝트 안내에서 실행 방법과 이용 조건을 먼저 확인하세요.

현재 등록된 완성작은 없습니다. 아래 표는 등록할 때 사용할 양식입니다.

| 결과물과 안내 | 대상과 교과 | 주요 기능 | 실행 또는 다운로드 | 로그인과 비용 | 확인 버전과 날짜 |
| --- | --- | --- | --- | --- | --- |
| 프로젝트 README 링크 | 작성 | 작성 | 확인한 링크 | 필요 여부 작성 | v1.0.0 / YYYY-MM-DD |

## 등록 방법

1. [공유 준비 안내](../guides/sharing.md)의 항목을 확인합니다.
2. 프로젝트 상태를 `공유 가능`으로 변경합니다.
3. 위 표의 양식 행을 실제 자료로 바꾸거나 새 행을 추가합니다.
4. 연수에서 사용할 버전과 실제 실행 링크를 [진행안](../training/facilitator-guide.md)에 기록합니다.

새 창이나 로그아웃 상태에서도 공유 링크가 열리는지 확인합니다. 코드 파일 주소는 실행 화면 주소와 구분해서 안내합니다.
