# 프로젝트 작업 공간

새 프로젝트마다 독립된 폴더를 만들고 [프로젝트 템플릿](../templates/project/README.md)의 파일을 복사합니다. 폴더 이름은 `ai-quiz`, `reading-helper`처럼 짧은 영문 이름을 권장합니다.

## 프로젝트 폴더 예시

```text
projects/
  ai-quiz/
    README.md       목적, 대상, 실행 방법, 수업 활용
    PROMPTS.md      사용한 프롬프트와 수정 과정
    CHANGELOG.md    버전별 변경 내용
    src/            HTML, 코드 등 편집 가능한 원본
    assets/         이미지와 소리 등 필요한 파일
    materials/      활동지, PDF, 발표 자료
```

필요한 폴더만 만듭니다. 외부 서비스에서 제작한 결과물은 공유 링크, 로그인 필요 여부, 복제 방법을 README에 기록합니다.

## 진행 중인 프로젝트

아직 등록된 프로젝트가 없습니다. 첫 프로젝트를 만들면 아래 양식으로 목록에 추가합니다.

| 프로젝트 README 링크 | 작성 | 작성 | 기획 | YYYY-MM-DD |
