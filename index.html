단풍 놀이터 사용 안내

1. 함께 준비해요

최신 Chrome 또는 Edge에서 파일을 열고 카메라로 시작을 누른 뒤 카메라 사용을 허용하세요. 마이크는 사용하지 않아요. 밝고 빛이 일정한 곳에서 카메라를 고정하고, 아이의 상체나 움직일 부위가 화면에 보이도록 조절하세요. 배경 TV나 선풍기는 꺼 주세요.

2. 아이의 속도대로 놀아요

시작 전 3초 동안 잠깐 가만히 있어 주세요. 그다음 화면 속 단풍에 손·팔·몸의 움직임을 겹쳐요. 화면에서 움직인 자리는 초록빛으로 표시돼요. 앉아서도 할 수 있어요. 잘 안 잡히면 민감도를 높이거나 단풍의 속도를 아주 천천히로 바꿔 주세요. 과하게 잡히면 민감도를 낮추고 움직임 다시 맞추기를 누르세요.

3. 바닥에 쌓이는 낙엽

잡은 잎은 모은 단풍에, 바닥에 닿은 잎은 놓친 낙엽에 한 장씩 더해져요. 놓친 낙엽은 다시 잡을 수 없고, 점수가 줄어들지는 않아요. 놀이 종료 시 두 숫자를 함께 확인할 수 있어요. 종료할 때 아직 공중에 있는 잎은 놓친 낙엽에 포함하지 않아요. 다시 시작하면 두 숫자와 바닥의 낙엽이 모두 초기화돼요.

놓친 낙엽은 누적 수예요. 바닥이 가득 차면 오래된 잎부터 정리해 화면을 가리지 않아요. 카메라로 놀 때도 숲 바닥은 그대로 보여요.

4. 카메라가 안 켜질 때

  • 파일 미리보기 대신 내려받은 HTML 파일을 브라우저에서 직접 여세요. 다른 화상회의 앱에서 카메라를 사용 중인지 확인하세요.
  • 사이트·운영체제의 카메라 권한이 차단돼 있다면 해당 설정에서 허용해 주세요.
  • 브라우저마다 로컬 파일(file://)의 카메라 지원이 달라요. 차단되면 학교에서 승인한 HTTPS 웹 서버 또는 이 기기의 localhost 웹 서버로 같은 파일을 여세요. 보안 경고를 무시하거나 보안 기능을 끄지 마세요.
  • Python이 이미 설치된 교사용 PC에서는 파일이 든 폴더에서 터미널에 python -m http.server 8000 --bind 127.0.0.1을 실행하고 브라우저에서 http://localhost:8000/autumn-leaf-motion-game.html을 열 수 있어요. 마친 뒤 터미널에서 Ctrl+C로 종료하세요.
  • 카메라 없이 마우스·터치 연습은 권한 없이 사용할 수 있어요. 화면 위에서 포인터나 손가락을 움직이면 그 주변 단풍이 잡혀요. 키보드로는 놀이 화면에 초점을 맞춘 뒤 방향키로 움직이고, 스페이스바로 잠깐 쉴 수 있어요.

개인정보와 감지 방식

카메라 영상은 이 기기의 메모리에서만 처리하며 저장하거나 전송하지 않아요. 이 파일은 외부 글꼴·라이브러리·서버 연결 없이 실행돼요. 얼굴, 손 관절이나 사람을 인식하는 AI가 아닌 연속 화면의 밝기 변화 비교 방식이에요. 옷이나 배경의 움직임, 급격한 조명 변화에도 반응할 수 있어요. 임상 평가·운동능력 측정 도구가 아니에요.

다른 탭으로 이동하면 놀이가 쉬어요. 카메라는 카메라 끄기·마무리 또는 시간 종료 시 꺼져요. 잠깐 쉬기만 누르면 카메라는 켜진 상태이므로 오래 쉴 땐 꺼 주세요.
