# 특수교육 맞춤 수업 도우미

학생 정보를 넣으면 **2022 개정 특수교육 교육과정**(교육부 고시 제2022-34호) 범위 안에서 개별화 수업안과 학습자료 초안을 만들어 주는 교사용 앱입니다. 결과는 초안이며, 성취기준·안전·학생 적합성은 교사가 최종 확인합니다.

## 쓰는 법

**claude.ai에서 바로 쓰기 (권장)**
`dist/artifact.html`을 claude.ai 아티팩트로 올리면, 여는 사람의 Claude 계정으로 바로 수업안을 만듭니다. API 키가 필요 없고, 처음 만들 때 한 번 사용 허락을 묻습니다.

1. 왼쪽에 학생 정보를 적습니다. ★ 3가지(학년, 장애 영역 또는 특성, 교과·단원 또는 목표)만 있어도 됩니다.
2. **수업안 만들기**를 누릅니다.
3. `/자료 1`, `/다른안`, `/통합`, `/가정연계`, `/평가`, `/간단` 단추나 추가 요청으로 다듬습니다.
4. 복사하거나 HTML로 저장해 인쇄합니다.

**다른 곳에서 열 때 (복사 모드)**
`dist/index.html`을 브라우저로 열거나 아무 웹 서버에 올리면 **복사 모드**로 동작합니다. **프롬프트 복사**를 누르면 지시문·참조표·학생 정보가 한 덩어리로 복사되어 ChatGPT·Gemini·Claude 대화창에 붙여 넣어 쓸 수 있습니다.

## 들어 있는 기능

- 교사 입력 양식(필수 3칸 + 선택 칸), 한 줄 요청
- 결과에서 `[성취기준 확인 필요]`, ⚠️ 안전 문구, `가정:` 줄, `[그림: …]` 자리를 눈에 띄게 표시하고 개수를 보여 줌
- **우리 학교 성취기준**: NCIC 원문을 붙여 넣으면 참조표 7번 칸에 들어가 그대로 인용됨 (이 브라우저에만 저장)
- 보내기 전 개인정보 점검: 전화번호, 주민등록번호, 이메일, 학교 이름, 학급·반, 날짜가 보이면 먼저 확인을 받음
- 작성 중인 양식과 결과는 이 탭에만 임시 저장되고, 탭을 닫으면 지워짐

## 파일 구성

| 경로 | 내용 |
|---|---|
| `prompts/1_시스템프롬프트.md` | 지시문. 검증·수정을 마친 최종본 그대로 (5,546자) |
| `prompts/2_교사입력양식.md` | 교사 입력 양식 (아래 '알아 둘 점' 참고) |
| `prompts/3_교육과정_참조표.md` | 교육과정 참조표, 지식 파일 (아래 '알아 둘 점' 참고) |
| `src/app.html` | 앱 화면과 동작 |
| `src/sample-output.md` | 처음 열었을 때 보이는 결과 예시 |
| `scripts/build.mjs` | 위 파일을 합쳐 `dist/`에 한 파일짜리 앱을 만듦 |
| `dist/artifact.html` | claude.ai 아티팩트용 |
| `dist/index.html` | 브라우저·웹 서버용 (복사 모드) |
| `tests/app.test.mjs` | Chromium에서 앱을 직접 조작하는 테스트 |

## 고치고 다시 만들기

```bash
npm install
npm run build   # prompts/·src/ → dist/
npm test        # build + 브라우저 테스트
```

지시문이나 참조표를 바꾸려면 `prompts/`의 파일을 고친 뒤 `npm run build`를 실행합니다. 참조표에는 `## 7.` 칸이 남아 있어야 합니다. 앱이 그 자리에 학교 성취기준을 넣습니다.

## 알아 둘 점

- `2_교사입력양식.md`와 `3_교육과정_참조표.md`는 **다시 작성한 판**입니다. 검증 후 최종본은 이 저장소에 없어서, 첫 판에 검증 단계의 수정 내역을 반영해 다시 썼습니다. 내려받아 둔 최종본이 있으면 같은 이름으로 덮어쓰고 `npm run build`를 실행하세요. 지시문(`1_시스템프롬프트.md`)은 최종본 그대로입니다.
- `4_설치안내.md`(GPTs·Gems·Claude 프로젝트 설치 방법)는 이 앱이 그 역할을 대신하므로 넣지 않았습니다.
- 참조표의 `(확인 필요)` 항목은 고시 원문과 대조해야 합니다: 기본 교육과정 교과 구성(실과 편성 학년, 초등 '진로와 직업', 중·고 선택 교과), 일상생활 활동의 영역과 시수 기준, 장애 영역별 교육 내용과 고교 전문 교과, 국가교육위원회 고시 제2026-2호, 시행령 [별표].
- 개인정보 점검은 형식이 뚜렷한 정보만 찾습니다. 학생 이름은 찾지 못하니 가명을 쓰세요.
