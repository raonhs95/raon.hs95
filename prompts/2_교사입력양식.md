# 학생 맞춤 수업 요청 양식

> **개인정보**: 실명(다른 학생 포함), 학교명, 학급·반, 생년월일, 연락처, 진단서·검사지 원문, 약 이름은 적지 마세요.
> **학생 A**처럼 가명을 쓰되, 가명만으로는 충분하지 않습니다. 장애·건강 정보는 민감정보이므로 수업에 필요한 기능적 특성으로 일반화해서 적어 주세요(예: "두 단계 지시를 이해함").
> ★ 표시 3개만 채워도 됩니다. 나머지는 적을수록 더 잘 맞춘 결과가 나옵니다.

```
★ 학년(필요하면 만 나이): 
★ 장애 영역 또는 주요 특성: 
★ 교과·단원 또는 수업 목표: 

적용 교육과정: (공통 / 기본 / 선택 중심 / 모름)
성취기준(개정 연도·교육과정 구분과 함께, 코드와 문구 그대로): 
IEP 목표(문구 그대로): 
현재 수행 수준(할 수 있는 것 / 도움이 필요한 것): 
의사소통 방식: (구어 / 단어 수준 / AAC / 수어 / 점자 / 몸짓 등)
강점·좋아하는 것: 
감각·운동 특성: 
행동 특성·주의할 점: 
보조공학: 
수업 형태: (개별 / 소집단 / 통합학급)   시간: (  )분
소집단이면 학생별 1줄: 
특별히 원하는 결과물: (활동지 / 그림카드 / 과제분석표 / 평가지 등)
안전 주의(알레르기, 발작, 삼킴, 식이 지침 등): 
```

## 작성 예시

```
★ 학년(필요하면 만 나이): 중학교 2학년
★ 장애 영역 또는 주요 특성: 자폐성장애. 일과가 바뀌면 불안해함. 짧은 문장으로 말함
★ 교과·단원 또는 수업 목표: 수학 – 돈 계산(1,000원 단위)

적용 교육과정: 기본 교육과정
현재 수행 수준: 1,000원짜리 지폐는 알아봄. 거스름돈 계산은 어려움
강점·좋아하는 것: 지하철 노선도, 편의점 간식
감각·운동 특성: 시끄러운 소리에 귀를 막음
수업 형태: 소집단 3명   시간: 45분
소집단이면 학생별 1줄:
- 학생 B: 지적장애, 100원·500원 동전을 구분함
- 학생 C: 자폐성장애, 구어 대신 태블릿 AAC 사용
특별히 원하는 결과물: 편의점 역할놀이 활동지
```

## 빠른 요청 예시 (한 줄)

- `초4 지적장애, 국어 낱말 읽기, 그림 좋아함, /간단`
- `고1 지체장애(휠체어, 손 사용 제한), 진로와 직업 – 사무 보조, /자료`
- `초2 청각장애(수어 사용), 통합학급 '우리 동네' 주제, /통합`

## 단축 명령

| 명령 | 하는 일 |
|---|---|
| `/간단` | 학생 요약·교육과정 연계·수업 아이디어 1안·학습자료만 짧게 |
| `/자료 [안 번호]` | 해당 안의 학습자료만 |
| `/통합` | 통합학급에서 함께 쓰는 버전 |
| `/가정연계` | 가정 연계 활동과 학부모 안내문 |
| `/평가` | 평가 도구만 |
| `/다른안` | 활동 방식이 다른 수업 아이디어 2안 |
